# กติกาการปิดงานโครงการ พระบาท พลัส

มีผลตั้งแต่ 4 ตุลาคม 2569

1. ทุกงานที่ดำเนินการเสร็จ ต้องรายงานผลทุกครั้ง
2. รายงานผลต้องระบุอย่างน้อย: สิ่งที่ทำ, ผลทดสอบ, สถานะระบบ, ข้อจำกัด/ความเสี่ยง, และสิ่งที่ยังไม่จบ
3. ถ้ามีแผนพัฒนาหรือปรับปรุงต่อ ต้องแจ้งแผนพร้อมรายงานผลในครั้งเดียวกัน
4. ห้ามสรุปว่า “เสร็จ” หากยังไม่ได้ทดสอบเส้นทางหลักหรือยังมีจุดค้างที่กระทบการใช้งานจริง
5. การทดสอบที่อาจส่ง LINE/แก้ข้อมูลจริง ต้องระบุชัดว่าเป็น dry-run หรือ live และหลีกเลี่ยง live send เว้นแต่ได้รับคำสั่ง
6. การปรับระบบต้องคงหลัก: JHCIS read-only สำหรับงานรายงานทั่วไป, Cloud GPS เป็น authoritative, และไม่เปิด CID/PID/raw LINE user ID เกินจำเป็น

รูปแบบปิดงานมาตรฐาน:
- ผลดำเนินการ
- ผลทดสอบ
- สถานะปัจจุบัน
- ความเสี่ยง/ข้อจำกัด
- แผนพัฒนาต่อ (ถ้ามี)
