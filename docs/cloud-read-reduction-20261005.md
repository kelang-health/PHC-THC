# ลดการโหลด Cloud ซ้ำ — 5 ตุลาคม 2569

ดำเนินการรุ่น 2.0.149:
- รายชื่อสุขภาพใช้แคชในหน่วยความจำ 2 นาที แยกตามตัวกรอง/ขอบเขตเดิม
- ประวัติคัดกรอง 50 รายการใช้แคช 5 นาที แยกผู้ใช้งาน รวมคำขอพร้อมกัน และไม่โหลดเมื่อออกเมนูสุขภาพ
- บันทึกสำเร็จ/รีเซทการทดสอบ/กดรีเฟรช ล้างแคชประวัติและรายชื่อเพื่ออ่านค่าล่าสุด
- ภาพรวมคำขอผู้ดูแลใช้แคช 2 นาที
- ตรวจสถานะคำขอเพิ่มสมาชิกทุก 2 นาทีเฉพาะหน้าที่เปิดและมองเห็น หยุดเมื่อปิดหน้าต่าง มีตัวตรวจเพียงชุดเดียว
- ไม่เปลี่ยนข้อมูลฐานหรือระบบส่งคิว JHCIS

ขั้นตอนติดตาม:
1. รีเฟรชเว็บให้ใช้รุ่นล่าสุด
2. เปรียบเทียบยอด Egress ที่เพิ่มต่อวันในหน้า Usage โดยใช้ช่วงใช้งานที่ใกล้เคียงกัน
3. อ่าน log เฉพาะเมื่อเกิดปัญหา จำกัดเวลาและจำนวนผลลัพธ์ ไม่มีการดึง log ทั้งหมดอัตโนมัติ
4. หากยังเกิน Free ให้ตรวจ endpoint ที่ใช้ข้อมูลมากก่อนปรับ pagination/คอลัมน์รายงานเพิ่มเติม

การปรับนี้ไม่ล้างยอดโควตาที่ใช้ไปแล้ว และยังไม่มีค่าร้อยละลด Egress จากการใช้งานจริง

ตรวจสอบ: ทดสอบแคช/คำขอพร้อมกัน/แยกผู้ใช้/ล้างหลังเขียน/ไม่โหลดหน้าอื่น, ตัวตรวจคิวมี timer เดียวและหยุดเมื่อปิด, การบันทึก NCD ไม่เสียพฤติกรรมป้องกันกดซ้ำและคงข้อมูลเมื่อผิดพลาด
