# ผลทบทวนการตรวจสุขภาพก่อนคัดกรองผู้สูงอายุ 9 ด้าน

วันที่ 6 ตุลาคม 2569

## ผลตรวจและปรับปรุง

- ผู้สูงอายุที่มีทั้ง DM และ HT ต้องกรอกการตรวจสุขภาพเบื้องต้นก่อนบันทึก 9 ด้าน ตามด่านฐานข้อมูลที่เปิดใช้แล้ว
- ผู้ไม่มีทั้งสองโรคหรือมีโรคเดียวเดินตามขั้นตอน NCD เดิมได้
- ค่าครั้งก่อนเป็นข้อมูลเทียบ ช่องค่าที่วัดใหม่เริ่มว่าง
- แบบตรวจต้องกรอกครบ 8 ช่องตัวเลข: ส่วนสูง น้ำหนัก รอบเอว ความดันบน/ล่าง ชีพจร หายใจ อุณหภูมิ
- หากเครือข่ายผิดพลาดระหว่างเตรียมแบบตรวจ ระบบกลับไปแสดงปุ่มทำต่อเพื่อให้ลองใหม่ได้
- ข้อผิดพลาดจากด่านใหม่แสดงคำแนะนำภาษาไทย
- ผลเดิมก่อนวันที่เปิดใช้ด่านใหม่ยังเปิดดูและแก้ไขได้ตามตรรกะเดิม
- อ่านวันของ session ก่อนเลือกขั้นตอน เพื่อไม่บังคับแบบตรวจใหม่เมื่อทำต่อจาก session เก่า

## หลักฐานทดสอบ

ทดสอบเบราว์เซอร์ Edge แบบจำลองโดยไม่เชื่อมบัญชีหรือบันทึกข้อมูลผู้ใช้จริง:

1. ผู้มี DM+HT เปิดแบบตรวจครบ 8 ช่องและค่าเดิมไม่ถูกเติมอัตโนมัติ
2. กรอกไม่ครบหรือไม่ยืนยันการวัด ไม่เรียกบันทึก
3. ชีพจร 121 เตือนก่อนบันทึก และส่งค่าเมื่อผู้ใช้ยืนยันอีกครั้ง
4. ผู้ไม่มี DM/HT มีเฉพาะ DM และมีเฉพาะ HT เดินตามทาง NCD เดิม
5. แบบตรวจที่บันทึกไว้ใน session เดิมใช้ทำต่อได้
6. session ก่อน 6 ต.ค. 2569 ทำต่อได้ตามเดิม
7. เครือข่ายผิดพลาดกลับไปกดลองใหม่ได้
8. ผล 9 ด้านที่ครบแล้วยังเปิดดูผลเดิมได้

ตรวจฐาน Cloud แบบอ่านอย่างเดียว: RLS เปิดอยู่ ผู้ไม่ล็อกอินอ่านไม่ได้ ผู้ใช้เขียนตรงไม่ได้ trigger เปิดใช้งาน และเงื่อนไขเก็บผลประวัติยังอยู่

## ขอบเขตผลทดสอบ

เป็นการทดสอบพฤติกรรมหน้าจอด้วยข้อมูลจำลองและตรวจสิทธิ์/โครงสร้างฐานจริง ไม่ใช่การลงข้อมูลผู้รับบริการจริงครบวงจร Cloud → Local → JHCIS หรือยืนยันการส่งออก 43 แฟ้ม การเปลี่ยนแปลงรอบทบทวนนี้ไม่มีการแก้ข้อมูลผู้ใช้จริงหรือรีสตาร์ตบริการ
