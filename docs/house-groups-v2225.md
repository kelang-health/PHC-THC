# Cloud v2.0.181 — เมนูบ้านสามกลุ่ม

วันที่ 22 ตุลาคม 2569

- ทุกสิทธิ์มีเมนูบ้าน และปุ่ม บ้านดูแล / รอตรวจสอบ / บ้านว่าง เปิดที่บ้านดูแล แสดงครั้งละกลุ่ม ค้นหาในกลุ่มและโหลดเพิ่มครั้งละ 30 หลัง
- user เห็นบ้านที่รับผิดชอบ; staff เห็นบ้านในชุมชนตามสิทธิ์เดิม; admin เห็นบ้านทั้งหมด คิวตรวจทะเบียนยังใช้ขอบเขตเดิม รวมการดูทะเบียนชั่วคราวของ Staff ตามหมู่
- คิวตรวจทะเบียนมีลำดับก่อนกลุ่มบ้านดูแล/บ้านว่าง บ้านหนึ่งหลังจึงไม่ซ้ำกลุ่ม บ้านที่ขาดชุมชน/ผู้รับผิดชอบอยู่รอตรวจสอบ
- บ้านดูแลมีบุคคล active, service eligible, type 1/3 และไม่ได้ถูกตัดจากงานเชิงรุก บ้านไม่มีเป้าหมายและมีแต่ type 2 หรือไม่มีรายชื่อใน Cloud อยู่บ้านว่าง หากมีสถานะอื่นที่ยังต้องตรวจสอบให้อยู่รอตรวจสอบ
- บ้านว่างเป็นการจัดกลุ่มจากข้อมูลทะเบียน ไม่ใช่การรับรองสภาพกายภาพ การไม่มีรายชื่อใน Cloud จะแสดงว่ายังไม่ยืนยันการพักอาศัย
- user ได้รับเฉพาะจำนวน type 2 ไม่มีชื่อใน payload ของเมนู/ข้อมูลบ้าน ไม่มีปุ่มเปิดรายชื่อ
- admin/staff ต้องเปิดบ้านแล้วกดดูรายชื่อ จึงเรียก RPC ชื่อแยกต่างหาก เฉพาะบ้านในขอบเขตสิทธิ์ ข้อมูลมีชื่อและป้าย type 2 เท่านั้น มี READ audit ทุกครั้ง ไม่มีการแคชรายชื่อ ล้างเมื่อปิด/ซ่อน/ออกระบบ และป้องกันผลเรียกกลับช้าไปเปิดเผยในบ้านถัดไป
- บ้านโรงเรียน 84 หมู่ 6 HID 52010046170 HCODE 2360/2587 แสดงทะเบียนบ้านพิเศษแยก ไม่เพิ่มประชากร ไม่รวมสามกลุ่มเป้าหมาย ไม่เปิดรายชื่อ และไม่ลบประวัติ
- ไม่แก้ JHCIS, พิกัด Cloud, active flags, eligibility, target caches หรือประวัติคัดกรอง ไม่เพิ่มระบบสำรวจลูกน้ำ คำขอบ้านภาคสนามเดิมยังเข้าดู/แก้ไขได้ภายใต้รอตรวจสอบ

## การตรวจสอบ

- `node tests/house-groups-v2225.cjs`: UI ข้อมูลสมมติทั้งสามสิทธิ์ ใช้ markup เมนูและ CSS จริง ขนาดมือถือ 371px ทดสอบ default, สลับกลุ่ม, จำนวน, pagination, ค้นหา, เส้นทางบ้านดูแล/ตรวจทะเบียน, ไม่โหลดชื่อล่วงหน้า, user ไม่มีปุ่มชื่อ, lazy names, escaping, ปิดก่อนผลชื่อกลับ, retry และ signout
- `node tests/house-registration-review-v2202.cjs`: ตรวจทะเบียนเดิม การตรวจเลข 11 หลัก การปฏิเสธเลขซ้ำ และเส้นทางเปิดจากเมนูใหม่
- `tests/house-groups-v2225.sql`: ฐานจริง ใช้ profile ที่มีอยู่เพื่อทดสอบ role/scope และ rollback ทั้ง transaction รวม audit ที่เกิดจากการทดสอบ ไม่แก้บัญชีหรือทะเบียนจริง
- เปรียบเทียบ hash ก่อน/หลังของ health_persons, houses, target cache และประวัติคัดกรอง รวมจำนวน active/worklist และ type 2 Active
- ตรวจ metadata release, ข้อความหน้าเข้าสู่ระบบ และไฟล์ที่เผยแพร่จริงหลัง deploy

## ข้อจำกัด

จำนวนชื่ออ้างอิงทะเบียน Cloud ที่ sync ล่าสุด เมนูเก็บ cache 60 วินาทีและมีปุ่มโหลดล่าสุด การเปลี่ยนสถานะบ้านจริงยังใช้กระบวนการตรวจสอบเดิม ไม่มีการเดาว่าบ้านรื้อถอนหรือมีคนพักจากชื่อหมู่/จำนวนศูนย์ การทดสอบหน้าจอสามสิทธิ์ใช้ข้อมูลสมมติ ส่วนสิทธิ์ฐานข้อมูลทดสอบกับฟังก์ชันจริงโดยจำลองบริบทบัญชีภายใน transaction
