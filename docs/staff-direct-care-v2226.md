# Cloud v2.0.183 — บ้านดูแลของ Staff

22 ตุลาคม 2569

ปุ่มบ้านดูแลของ Staff แสดงเฉพาะบ้านที่เข้าเกณฑ์บ้านดูแลเดิม และ `houses.volunteer_pid = profiles.volunteer_pid` ของบัญชีนั้น โดยต้องมี volunteer_pid จริง จำนวนและผลค้นหา/แบ่งหน้าใช้รายการเดียวกัน ไม่มีการนำบ้านของ อสม. คนอื่นในชุมชนมารวมในปุ่มนี้

เพิ่มข้อความอธิบายว่า บ้านดูแลแสดงเฉพาะบ้านที่ผูกกับคุณโดยตรง และดูบ้านทั้งชุมชนได้ที่เมนูชุมชน เปลี่ยนป้ายเมนู staff เป็นบ้านที่รับผิดชอบ

การเปลี่ยนนี้เป็นตัวกรองการแสดงผลเฉพาะกลุ่ม care ใน `private.house_groups_v2225()` เท่านั้น กลุ่มรอตรวจสอบ บ้านว่าง บ้านพิเศษ เมนูชุมชน สิทธิ์เปิดบ้าน/รายชื่อ type 2 ของ staff และข้อมูล/เป้าหมายสุขภาพยังใช้กฎเดิม ไม่มีการเปลี่ยนผู้รับผิดชอบบ้านจริง user/admin ใช้รายการเดิม

ผลทดสอบก่อนติดตั้ง: เทียบรายการจริงก่อน/หลังใน transaction แล้ว rollback สำหรับ Staff active ครบ 16 บัญชี รายการใหม่ตรงกับรายการเดิมที่กรองผู้รับผิดชอบโดยตรงทุกหลัง กลุ่มอื่นเหมือนเดิมทั้งหมด Staff มีบ้านดูแลหลังกรอง 8–20 หลังต่อบัญชี ตัวอย่าง admin และ user รายการทุกกลุ่มเหมือนเดิม

UI ใช้ข้อมูลสมมติทดสอบครบสามสิทธิ์ พร้อมยืนยันข้อความขอบเขตแสดงเฉพาะ Staff ในแท็บบ้านดูแล ส่วนฐานข้อมูลตรวจฟังก์ชันจริงและเทียบ hash ทะเบียนบ้าน/ประชากร/target cache/ประวัติคัดกรองก่อนและหลัง ตรวจเวอร์ชันและไฟล์เว็บจริงหลังเผยแพร่
