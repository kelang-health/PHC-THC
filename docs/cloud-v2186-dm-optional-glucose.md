# Cloud v2.0.186 — น้ำตาลเป็นตัวเลือกสำหรับผู้มีประวัติเบาหวาน

- ผู้มี `health_persons.has_dm=true` เห็นข้อความ “มีประวัติโรคเบาหวานแล้ว สามารถข้ามหรือกรอกระดับน้ำตาลได้” และบันทึกโดยเว้นน้ำตาลว่างได้
- ผู้ไม่มีประวัติเบาหวานยังต้องกรอกน้ำตาล หากกรอกค่าให้เลือกสถานะก่อนตรวจและตรวจช่วง 20–700 ตามเดิม
- ค่าว่างส่งและเก็บเป็น NULL ไม่ใช้ 0; แสดงข้ามการวัด และไม่เตือนน้ำตาลต่ำจากค่าว่าง
- ฐานข้อมูลตรวจประวัติ DM จากทะเบียนเอง โดยรักษา authorization, BP, pulse และ request idempotency เดิม
- meta phc-release และข้อความหน้าเข้าสู่ระบบเป็น 2.0.186

การทดสอบ: SQL/PGlite ด้วยข้อมูลจำลอง (DM ข้าม, HT-only ข้ามไม่ได้, ค่าจริง, ขอบเขต, น้ำตาลต่ำ, สิทธิ์), แบบฟอร์มมือถือจริงใน browser, pulse, measurement warnings, fiscal repeat, save/retry feedback, migration integrity และ JavaScript syntax ผ่าน ไม่มีการสร้างผลคัดกรองทดสอบในฐาน production
